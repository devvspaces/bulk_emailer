Getting started

Send your first campaign in three steps.

  1. Add an email manager in Settings. This is the provider that actually delivers your mail (SendGrid, ZeptoMail, or any SMTP server).
  2. Upload your recipient list on the Send Email page — a CSV or Excel file with an email column.
  3. Compose and send. Write your subject and message, pick the row range, and hit send.

Email managers

An email manager stores the credentials for one delivery provider. You can create as many as you need and pick one per campaign.

SendGrid

Create an API key in your SendGrid dashboard and paste it into the api_key field.

ZeptoMail

Paste your ZeptoMail auth token into the api_key field.

SMTP server

Provide the server host, port, username and password. Common values:

Gmail
Host: smtp.gmail.com Port: 587 (or 465 for SSL) Username: your.email@gmail.com Password: a Google App Password (not your normal password)

Any port other than 465 uses STARTTLS automatically.

Preparing your file

Upload a CSV, XLS, XLSX or GZ file. The first row must contain column headers.

  • Email column — pick the header that holds email addresses from the Email column dropdown after uploading.
  • Row range — use the slider or the start/end fields to send to a subset of rows.

Example file:

email,firstname,lastname ada@example.com,Ada,Lovelace grace@example.com,Grace,Hopper

Personalization

Insert values from any column by wrapping the header name in underscores.

Hello _firstname_, thanks for joining us!

For the example file above, this renders as “Hello Ada, thanks for joining us!” for the first recipient.

Use the exact column header (case-sensitive). If your column is First Name, the placeholder is _First Name_.

Sending SMS

  1. Set TWILIO_SID and TWILIO_TOKEN in your .env file.
  2. Enter your Twilio sender number (e.g. +14155552671).
  3. Upload a file with a phone column.
  4. Compose your message and send.

Troubleshooting

Emails aren't sending

Check your email manager credentials in Settings. If BLOCK_EMAIL=True is set in .env, sending is disabled.

My columns don't appear

Upload the file first — the email column dropdown is populated from the file's header row.

Recipients selected shows 0

Make sure your file has data rows below the header and that the start/end range is valid.

Where is my data stored?

Your database (db.sqlite3), logs, media and static files are kept next to the application binary.
